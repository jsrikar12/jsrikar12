### [3D Labs](https://github.com/jsrikar12/3D-Labs)

A Windows desktop studio that turns scripts or structured scene blueprints into 3D explainers. It combines procedural scene assembly, timed narration, storyboard review, and resumable Blender rendering. Optional free-form scene composition with Ollama is experimental.

**Stack** · Python, Blender, PySide6, Piper, FFmpeg, Ollama (optional)

**Verification** · The [V3 verification report](https://github.com/jsrikar12/3D-Labs/blob/main/VERIFICATION.md) records 31 passing tests, a successful resume of a cancelled native render, and a verified 40-second, 1080 × 1920 engine export at 30 FPS. The engine export reused V2 render frames. The report documents newly rendered V3 scenes separately.

### [AutoClip Studio](https://github.com/jsrikar12/AutoClip-Studio)

A local Windows editor that suggests highlights from GTA gameplay and long-form dialogue. The workflow lets you review and approve cuts, edit captions and framing, and export vertical MP4s individually or in a batch.

**Stack** · Python, Tkinter, Faster-Whisper, OpenCV, NumPy, PyAV, FFmpeg, Ollama (optional)

**Verification** · The [V4 benchmark](https://github.com/jsrikar12/AutoClip-Studio/blob/main/V4-BENCHMARK.md) reports 24 initial candidates and 11 retained after a denser confirmation pass on one 10-minute GTA V segment. The report documents false positives and a missed event.

### [API Monitoring & Alerting Platform](https://github.com/jsrikar12/api-monitoring-alerting-platform)

A Python backend that runs scheduled and on-demand HTTP checks, stores status and latency in PostgreSQL, and opens one alert after three consecutive failures. A successful check resolves the alert. Swagger UI exposes configuration, status, and history.

**Stack** · Python, FastAPI, PostgreSQL, SQLAlchemy, HTTPX, APScheduler, Docker Compose, pytest

**Verification** · The [verification record](https://github.com/jsrikar12/api-monitoring-alerting-platform/blob/main/docs/VERIFICATION.md) reports 32 passing tests on SQLite and 32 on PostgreSQL. It also documents a live HTTPS scheduler check and alert recovery using controlled upstream responses. Docker Compose configuration passed validation. Runtime verification used native PostgreSQL.
